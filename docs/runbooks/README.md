# Runbooks

Step-by-step operational procedures. Add one after the first time you solve a problem.

| Runbook | When to use it |
|---|---|
| [`upstream-feed-failure.md`](./upstream-feed-failure.md) | An upstream source returns a 4xx/5xx, changes its schema, or starts returning obviously wrong values |
| [`release.md`](./release.md) | Cutting a tagged release |
| [`rollback.md`](./rollback.md) | A deploy broke the live site — get the last-known-good back fast |
